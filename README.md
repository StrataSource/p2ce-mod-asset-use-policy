# P2:CE Mod Asset Use Policies

The purpose of this repo is to hold the policies of different Source Engine mod projects surrounding asset use and redistribution in other mods.

If you are the author of a Source Engine mod and would like to allow people to use the assets from your mod on the P2:CE workshop, please contact us to let us know the terms or preferably open a PR to this repository. We will make sure that content on our workshop follows the rules you have set here.
